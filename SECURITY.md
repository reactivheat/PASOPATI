# Security reporting / Pelaporan keamanan

## English

PASOPATI is unreleased alpha software. No stable release or support lifetime is
promised; fixes currently target the main branch. A passing test suite is not a
security audit. Use only on explicitly authorized targets; recon output is not
proof of security or a confirmed vulnerability.

The availability of a private vulnerability-reporting channel has not been verified.
Do not publish credentials, target details, real scan reports,
exploit instructions or sensitive proof-of-concept material in public issues.
You may ask the [owner](https://github.com/reactivheat) to establish a private
contact using a non-sensitive request. Wait for an agreed private channel before
sharing sensitive details. No response SLA, bounty or confidentiality guarantee
is implied by this document. Do not use real third-party targets to demonstrate bugs.

## Bahasa Indonesia

PASOPATI masih alpha dan belum dirilis. Belum ada jaminan rilis stabil atau masa
dukungan; perbaikan saat ini ditujukan ke main. Tes lulus bukan audit keamanan.
Gunakan hanya pada target berizin eksplisit; output recon bukan bukti aman atau
kerentanan terkonfirmasi.

Ketersediaan kanal pelaporan kerentanan privat belum diverifikasi.
Jangan membuka kredensial, detail target, laporan nyata, instruksi exploit atau
PoC sensitif di issue publik. Anda dapat meminta [pemilik](https://github.com/reactivheat)
menetapkan kontak privat melalui permintaan tanpa informasi sensitif. Tunggu kanal
privat yang disepakati sebelum berbagi detail sensitif. Dokumen ini bukan janji
SLA respons, bounty atau jaminan kerahasiaan. Jangan memakai target pihak ketiga
nyata untuk mendemonstrasikan bug.
